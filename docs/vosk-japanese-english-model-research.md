# Vosk日英混合音声認識モデルの調査報告書

## 概要

このドキュメントは、Unity環境でONNX形式で動作する日英混合音声認識モデルの開発について、Vosk APIを中心に調査した結果をまとめたものです。特に48MB程度の小型モデルで高精度を実現する方法に焦点を当てています。

## 1. 現状の分析

### 1.1 利用可能な日本語モデル
- **vosk-model-small-ja-0.22**: 48MB、CER 9.52（CSJ）/17.07（TED10k）
- **vosk-model-ja-0.22**: 1GB、CER 8.40（CSJ）/13.91（TED10k）

小型モデルは48MBと軽量だが、大型モデルと比較して約20%精度が劣る。

### 1.2 Voskのアーキテクチャ
- **コア**: Kaldiフレームワークベース（C++実装）
- **音響モデル**: TDNN（Time Delay Neural Network）
- **言語モデル**: FST（Finite State Transducer）形式
- **話者適応**: i-vectorによる実装

## 2. 日英混合モデルの作成方法

### 2.1 マルチリンガルアプローチ
現在のVoskは単一言語モデルが主流だが、以下の方法で日英混合モデルを作成可能：

1. **共通音素セットの構築**
   - 日本語と英語の音素を統合したセットを作成
   - Kaldiのmultilingual chain model trainingを使用

2. **データ準備**
   - 日本語音声データ（CSJ、JSUT等）
   - 英語音声データ（LibriSpeech等）
   - コードスイッチングデータ（理想的には日英混合会話データ）

3. **トレーニング手順**
   ```bash
   # 各言語のegsファイルを生成
   steps/chain/get_egs.sh
   # 複数言語のegsを結合
   steps/chain/multilingual/combine_egs.sh
   ```

### 2.2 2024年の最新動向
- **ReazonSpeech v2.1**: 日本語ASRの最新モデル、英日バイリンガルモデルの開発計画あり
- **CS-Dialogue**: 中国語-英語のコードスイッチングデータセット（104時間）が公開、同様のアプローチが日英でも可能

## 3. 小型モデルの精度向上手法

### 3.1 モデル圧縮技術

#### 量子化（Quantization）
- **BitDistiller**: 4ビット以下の精度でも高性能を維持
- **AWQ**: 重要なパラメータの1%を保持し、残りを4ビット量子化で8倍圧縮
- **1ビット量子化**: メモリ使用量を90%削減

#### プルーニング（Pruning）
- **構造化プルーニング**: チャネル、カーネル、レイヤー単位での削減
- **非構造化プルーニング**: 閾値以下の重みを個別に削除
- VGG16の例：13倍のサイズ削減で5倍の高速化を実現

#### 知識蒸留（Knowledge Distillation）
- 大型モデルから小型モデルへの知識転移
- **LLM-QAT**: データフリー蒸留技術の適用
- **ZeroQuant-FP**: 段階的な量子化と教師モデルの活用

### 3.2 ドメイン適応

#### Voskモデル適応の要件
- **データ量**: 最低1時間の音声データで音響モデル適応可能
- **テキストデータ**: 100MB以上のドメイン特化テキストが理想的
- **ハードウェア**: 32GB RAM、100GB ディスクスペース（Linux環境）

#### 適応プロセス
1. ドメイン特化データの収集
2. Kaldiフォーマットへの変換
3. 言語モデルの再コンパイル
4. 音響モデルのファインチューニング

### 3.3 精度向上の実績
- **技術用語認識**: カスタム言語モデルでWER大幅改善
- **雑音環境**: ドメイン適応により20%の精度向上を達成
- **アクセント対応**: 多様な話者サンプルによる適応で改善

## 4. Unity/ONNX対応

### 4.1 現状の課題
- VoskはKaldiのnnet3フォーマットを使用、ONNXに直接対応していない
- Unity統合にはネイティブプラグインとして実装が必要

### 4.2 ONNX変換の選択肢

#### 1. Kaldi-ONNX（XiaoMi製）
- Nnet2/Nnet3モデルをONNXに変換
- RNN/TDNNをDAGライクなネットワークに変換
- モバイルデバイスでの高速推論を実現

#### 2. Sherpa-ONNX（Next-gen Kaldi）
- ONNX Runtimeを使用した音声認識
- 12のプログラミング言語に対応
- オフライン動作、組み込みシステム対応

#### 3. カスタム実装
1. Kaldiモデルの構造解析
2. PyTorch/TensorFlowで再実装
3. ONNXへのエクスポート

### 4.3 Unity統合の推奨アプローチ
1. **Sherpa-ONNX**を使用（最も実装が簡単）
2. 既存Voskモデルを**Kaldi-ONNX**で変換
3. Unity用のONNX Runtimeプラグインを実装

## 9. 最新の音声認識技術動向（2024年）

### 9.1 最新の音声認識論文・手法

#### Whisperの進化
- **Whisper拡張**: Wav2Vec 2.0と組み合わせることで、低リソース言語（アラビア語、ロシア語、ポルトガル語）でWER 33.9%、CER 53.2%の改善を達成
- **ROAR**: Wav2Vec 2.0ベースのASRシステム向けに開発された新しい最適化手法

#### 離散音声ユニット
- **Interspeech 2024チャレンジ**: 離散音声ユニットを使用した音声処理に40の提出があり、自己教師あり学習（SSL）モデルのセマンティックトークンが有望な成果を示す

### 9.2 最新のOSS音声認識プロジェクト

#### WhisperX
- OpenAI Whisperの拡張版で、単語レベルのタイムスタンプと話者ダイアライゼーション機能を追加
- バッチ推論のサポート（通常のWhisperには非対応）
- VADベースのセグメント転写

#### Faster-whisper
- CTranslate2を使用したWhisperの高速再実装
- 元のWhisperモデルと同等の精度を維持しながら、大幅な速度向上を実現

#### SpeechBrain
- PyTorchベースのオープンソースツールキット
- 音声認識、音声強調、話者認識、音声翻訳など包括的な機能
- 自己教師あり学習と拡散モデルを含む最新のディープラーニング技術との統合

#### ESPnet
- エンドツーエンドの音声処理ツールキット
- OpenAI Whisperモデルの統合
- ストリーミングASRのサポート
- Transformer、Conformer、各種ニューラルビームフォーマーなど豊富なモデルアーキテクチャ

### 9.3 Transformer/Conformerベースの最新アプローチ

#### Zipformer（2024年の注目技術）
- Conformerの改良版で、より高速でメモリ効率的
- 主な改良点：
  1. U-Net風のエンコーダー構造（中間スタックが低フレームレートで動作）
  2. 効率化のために注意重みを再利用する再編成されたブロック構造
  3. BiasNormと呼ばれる修正版LayerNorm
  4. 新しい活性化関数SwooshRとSwooshL
- 性能：50%以上のFLOPs削減でConformer-Lを上回る性能

#### Branchformer
- 並列ブランチを使用して様々な範囲のコンテキストをモデル化
- 一つのブランチが畳み込みゲーティングMLPでローカルコンテキストを捕捉
- もう一つのブランチが長距離依存関係を学習

#### E-Branchformer
- Branchformerの拡張版
- LibriSpeechで新しいSOTA：test-clean 1.81%、test-other 3.65% WER
- 効果的なマージ手法と追加のポイントワイズモジュールを採用

### 9.4 自己教師あり学習の最新手法

#### BEST-RQ（2024年の最新改良）
- **最適化されたBEST-RQ**: KLダイバージェンスを追加の正則化損失として使用
- マルチコードブック拡張：6コードブックでtest-clean 23.8%、test-other 30.6%の相対的WER改善
- **NEST-RQ**: 因果エンコーダーと次トークン予測を使用する新しい変種
  - ストリーミングASRで優れた性能
  - 非ストリーミングASRでBEST-RQと同等の性能

#### 継続的な進化
- Wav2Vec2、HuBERT、WavLMは多言語対応で継続的に改善
- 40以上の言語をカバーする事前学習モデルが利用可能
- 低リソース言語への適応が活発に研究されている

### 9.5 エンドツーエンドモデルの軽量化手法

#### DistilWhisper
- whisper-smallの言語固有エキスパートを使用した軽量モジュラーASRファインチューニング
- whisper-large-v2からの知識蒸留
- 標準のファインチューニングやLoRAアダプターよりも効果的

#### エッジデバイス向け量子化（2024年）
- **Edge-ASR**: 自動音声認識モデルの低ビット量子化
- FP32からFP16への変更で、音声転写のエネルギー消費を半減
- 性能劣化は最小限に抑制
- Post-Training Quantization（PTQ）が効果的な手法として確立

#### 主要な軽量化戦略
1. **量子化**: INT8、FP16への変換で大幅なサイズ削減
2. **知識蒸留**: 大型モデルから小型モデルへの効果的な知識転移
3. **プルーニング**: 不要なパラメータの削除
4. **アーキテクチャ最適化**: Zipformerのような効率的な設計

### 9.6 日英混合モデルへの応用可能性

これらの最新技術を組み合わせることで、48MB程度の日英混合モデルの実現可能性がさらに高まります：

1. **Zipformerアーキテクチャの採用**: 50%以上のFLOPs削減で高性能を維持
2. **BEST-RQ/NEST-RQの活用**: 効率的な自己教師あり学習
3. **DistilWhisperアプローチ**: 言語固有エキスパートによる効果的な多言語対応
