# 実装優先順位戦略（GPU時間ベース）

## GPU時間の比較

| アプローチ | GPU時間 | 精度向上期待値 | 実装難易度 | リスク |
|-----------|---------|---------------|-----------|--------|
| ドメイン適応 | 8-16時間 | 5-10% | 低 | 極小 |
| DistilWhisper | 100-200時間 | 18-25% | 中 | 中（Whisper移行） |
| BEST-RQ/NEST-RQ | 300-500時間 | 20-30% | 高 | 中 |
| Zipformer | 800-1200時間 | 15-20% | 高 | 高（完全再訓練） |

## 推奨実装順序

### 🥇 Step 1: ドメイン適応から開始（必須）

**理由**：
- GPU時間：最小（1-2日）
- 即座に5-10%改善
- 他の手法の効果も増幅
- リスクゼロ

**具体的作業**：
```bash
# 1. 雑談会話テキストデータ収集（100MB以上）
# 2. 言語モデル再構築
./prepare_lm.sh --text corpus.txt --model vosk-model-small-ja-0.22
# GPU時間: 8-16時間
```

### 🥈 Step 2A: DistilWhisperアプローチ（Whisper移行OK の場合）

**理由**：
- GPU時間：100-200時間（1週間程度）
- 実績のある手法
- WhisperXで高速化も可能
- 日英混合に強い

**実装手順**：
```python
# 1. Whisper-smallの日本語ファインチューニング（50時間）
# 2. 知識蒸留で軽量化（100時間）
# 3. ONNX変換（数時間）
```

### 🥈 Step 2B: BEST-RQ実装（Vosk維持の場合）

**理由**：
- Voskエコシステム維持
- 最新の自己教師あり学習
- ラベルなしデータ活用可能

**実装手順**：
```python
# 1. ラベルなし日本語音声データ収集（1000時間分）
# 2. BEST-RQ事前学習（200-300時間）
# 3. ファインチューニング（100時間）
```

### 🥉 Step 3: Zipformer（長期的投資として）

**理由**：
- 最も効率的なアーキテクチャ
- 将来性が高い
- ただしGPU時間が膨大

**いつ実施すべきか**：
- Step 1, 2で目標精度を達成できない場合
- 長期的な競争優位性が必要な場合
- 十分なGPUリソースが確保できた場合

## 実践的な開始プラン

### Week 1-2: ドメイン適応
```bash
# GPU: V100×1台×16時間
# データ準備
python prepare_conversation_data.py

# 言語モデル再構築
./retrain_lm.sh --gpu 0
```

### Week 3-4: 評価と次の選択
1. ドメイン適応の効果測定
2. 目標との差分確認
3. 次のアプローチ選択：
   - 10%以上改善 → 様子見
   - 10%未満 → DistilWhisperまたはBEST-RQへ

### Week 5-8: 本格実装
```python
# DistilWhisperの場合（GPU: A100×2台×100時間）
python distil_whisper_train.py \
    --teacher "openai/whisper-small" \
    --data "japanese_speech_data" \
    --output_size 48MB

# BEST-RQの場合（GPU: A100×4台×300時間）
python best_rq_pretrain.py \
    --unlabeled_data "1000h_japanese_audio" \
    --num_codebooks 6
```

## コスト効率を最大化するコツ

### 1. 段階的評価
- 各ステップ後に必ず評価
- 目標達成したら次のステップは保留

### 2. データの再利用
- ドメイン適応で集めたデータは他でも活用
- 評価セットは統一して比較可能に

### 3. 並列実験
- 小規模実験で手法を比較
- 最も有望な手法にGPUリソース集中

## 判断フローチャート

```
スタート
    ↓
ドメイン適応（16 GPU時間）
    ↓
精度向上15%以上？
    ├─ Yes → 完了（最高のコスパ！）
    └─ No → 次へ
         ↓
    Whisper移行OK？
    ├─ Yes → DistilWhisper（200 GPU時間）
    └─ No → BEST-RQ（500 GPU時間）
         ↓
    精度向上20%以上？
    ├─ Yes → 完了
    └─ No → Zipformer検討（1000 GPU時間）
```

## 結論

**必ずドメイン適応から始める**べきです。これは：
- 最小のGPU時間（16時間）
- 即効性がある（1-2週間）
- 他の手法と相乗効果
- 失敗してもダメージ最小

その後、結果を見て次のステップを判断することで、無駄なGPU時間を避けられます。
